# Атлас права

Персональный тренажёр для долговременного запоминания юридических знаний. Вопросы готовит Claude, приложение на Android показывает их по алгоритму интервального повторения FSRS, а прогресс виден на карте знаний: области открываются после «разведки» и светятся тем ярче, чем лучше вы их помните сегодня.

- **Установка и сервер:** [SETUP.md](SETUP.md)
- **Колода из документа прямо на телефоне:** кнопка «+» на главном экране или «Поделиться» документом (PDF, Word, RTF, текст) в «Атлас права». DeepSeek создаёт вопросы по частям документа, раскладывает их по существующим книгам или заводит новые, а приложение проверяет, что цитата-обоснование у каждого вопроса действительно есть в документе. Перед добавлением показывается предпросмотр.
- **Как готовить вопросы в Claude:** [docs/generation-prompt.md](docs/generation-prompt.md)
- **Формат колоды:** [docs/question-format.md](docs/question-format.md), пример — [examples/sample-deck.json](examples/sample-deck.json)

## Устройство

| Каталог | Что внутри |
| --- | --- |
| `core/` | Логика без Android: FSRS-5, планировщик сессий, проверка и импорт колод, раскладка карты. Тесты: `SKIP_ANDROID=1 ./gradlew :core:test`. |
| `app/` | Приложение на Jetpack Compose: карта, сессия, итог, настройки. Состояние хранится в одном JSON-файле на телефоне. |
| `server/` | Cloudflare Worker + D1: страница загрузки колод, синхронизация, резервная копия ответов, оценка свободных ответов через Claude. |

## Методика

- Практика извлечения: вопросы на воспроизведение, ответ своими словами или вслух.
- Интервальное повторение FSRS с целевой вероятностью вспомнить 90%.
- Перемешивание: соседние вопросы сессии из разных тем.
- Разведка (предтестирование) перед открытием новой области.
- Оценка уверенности перед ответом; уверенные ошибки выделяются для разбора.
- Сессия под выбранное время, без таймеров на ответ и без штрафов за пропуски.

Сборка APK идёт в GitHub Actions; свежая версия для телефона — в релизе `apk-latest`.
