# Формат колоды (schema_version 1.0)

Колода — один JSON-файл: описание (`deck`), темы-области (`topics`) и вопросы (`items`). Пример: [`examples/sample-deck.json`](../examples/sample-deck.json). Промпт для генерации: [`generation-prompt.md`](generation-prompt.md).

## deck

| Поле | Обязательно | Смысл |
| --- | --- | --- |
| `id` | да | Постоянный идентификатор колоды латиницей. Повторная загрузка с тем же id заменяет колоду, сохраняя прогресс по совпадающим вопросам. |
| `title` | да | Название. |
| `world` | да | Мир на карте (отрасль права). Колоды с одинаковым миром показываются на одной карте. |
| `description` | нет | Для чего колода. |

## topics

| Поле | Обязательно | Смысл |
| --- | --- | --- |
| `id` | да | Идентификатор темы, уникальный в колоде. |
| `title` | да | Название области на карте, до 6 слов. |
| `world` | нет | Если тема относится к другому миру, чем колода. |
| `neighbors` | нет | id смысловых соседей: они окажутся рядом на карте. |

## items

| Поле | Обязательно | Смысл |
| --- | --- | --- |
| `id` | да | Постоянный уникальный id. К нему привязана история ответов. |
| `topic_id` | да | Тема из `topics`. |
| `prompt` | да | Вопрос. Для `cloze` — с пропуском `____`. |
| `answer` | да | Эталонный ответ со ссылкой на норму. |
| `format` | нет | `free_recall` (свободный ответ, оценивает LLM), `case_scenario` (ситуационная задача, тоже LLM), `self_check` (вспомнить и открыть ответ), `cloze`, `choice`. По умолчанию `self_check`. |
| `level` | нет | `fact`, `understand`, `apply`, `distinguish`. |
| `difficulty` | нет | 1–5, начальная оценка автора. |
| `key_points` | для `free_recall` | Тезисы эталона: `id`, `text`, `weight` (1–2), `required`. По ним LLM ставит оценку. |
| `common_errors` | нет | Типичные ошибки: помогают LLM распознать их в ответе. |
| `options`, `correct_option` | для `choice` | Варианты и индекс верного (с нуля). |
| `explanation` | нет | Разбор после ответа. |
| `why_prompt` | нет | Вопрос «почему…» для размышления после ответа. |
| `hints` | нет | Подсказки, открываются по одной. |
| `source` | нет | `title`, `locator` (статья, пункт), `url`. |
| `norms` | нет | Список норм. |
| `related_ids` | нет | Связанные вопросы. |
| `pretest` | нет | `true` — вопрос для «разведки» закрытой области. |
| `valid_as_of` | нет | Дата актуальности. Если норма изменилась, отметьте вопрос как неверный в приложении. |

Неизвестные поля игнорируются, поэтому формат можно расширять без поломки старых версий приложения.
