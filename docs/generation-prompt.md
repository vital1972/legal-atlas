# Промпт для генерации вопросов

Скопируйте текст ниже в Claude (или другую модель), заменив строки в квадратных скобках. Модель вернёт JSON, который загружается в приложение через «Поделиться», выбор файла или страницу сервера.

Подготовь колоду вопросов для моего тренажёра интервального повторения «Атлас права».

**Область:** [например: исковая давность в гражданском праве РФ]
**Зачем:** [например: готовлюсь к спору о взыскании задолженности по договору поставки, нужно освежить нормы и позиции ВС РФ]
**Мир на карте:** [отрасль, к которой относится область: «Гражданское право», «Арбитражный процесс», «Корпоративное право», «Банкротство», «Общая теория права» и т. п.]
**Объём:** [например: 25–35 вопросов, 4–6 тем]

Кто я: практикующий юрист с большим опытом. Не объясняй азы, но и не пропускай базовые нормы: колода должна позволить проверить, что я их помню точно.

## Требования к вопросам

1. **Один вопрос — одна мысль.** Не объединяй два факта в одном вопросе, кроме вопросов на различение.
2. **Смесь уровней:** примерно 40% `fact` (сроки, номера статей, перечни), 30% `understand` (почему норма устроена так), 30% `apply` и `distinguish` (ситуации, «чем отличается X от Y»).
3. **Форматы:** около половины `free_recall` (свободный ответ, его проверяет LLM по `key_points`), остальное `self_check`, `cloze` и `choice`. Используй `case_scenario` для 2–3 развёрнутых ситуационных задач в колоде.
4. **Ключевые тезисы.** Для `free_recall` и `case_scenario` обязательно 2–5 `key_points`; отметь `required: true` у тех, без которых ответ неверен. Вес 2 для главного, 1 для второстепенного.
5. **Типичные ошибки.** Где они есть, укажи в `common_errors` то, что юристы реально путают.
6. **Точность.** Ссылайся только на нормы и акты, в которых уверен. Указывай в `source.locator` статью и пункт. Если позиция ВС РФ спорная или ты не уверен в номере пункта постановления Пленума, не включай такой вопрос. Заполни `valid_as_of` сегодняшней датой.
7. **Разведка.** Отметь `pretest: true` у 1–2 вопросов в каждой теме: простые, но неочевидные вопросы, на которые интересно попробовать ответить до изучения.
8. **Обоснование по Фейнману.** К каждому `free_recall` и `case_scenario` добавь:
   - `why_prompt`: короткий вопрос «почему…», на который я отвечаю после основного ответа;
   - `rationale`: верное обоснование в 2–4 предложениях: какая норма или принцип и как из них следует ответ;
   - `rationale_quote`: дословная цитата из нормы или акта, на которой держится ответ (одно-два предложения). Только если уверен в тексте дословно; иначе не указывай это поле.
9. **Темы** (`topics`) — это области на карте. Укажи в `neighbors` смысловых соседей, чтобы связанные темы оказались рядом. Названия тем короткие (до 6 слов).
10. **Идентификаторы** постоянные и уникальные: `<deck.id>-001`, `<deck.id>-002`… При доработке колоды сохраняй id существующих вопросов, чтобы не потерять мой прогресс.

## Формат ответа

Верни **только JSON** без пояснений, по схеме:

```json
{
  "schema_version": "1.0",
  "deck": {"id": "latin-kebab-case", "title": "Название", "world": "Отрасль", "description": "Для чего колода"},
  "topics": [
    {"id": "topic-id", "title": "Название темы", "neighbors": ["other-topic-id"]}
  ],
  "items": [
    {
      "id": "deck-id-001",
      "topic_id": "topic-id",
      "level": "fact | understand | apply | distinguish",
      "format": "free_recall | self_check | cloze | choice | case_scenario",
      "difficulty": 1,
      "prompt": "Текст вопроса (для cloze — с пропуском ____)",
      "answer": "Эталонный ответ со ссылкой на норму",
      "key_points": [{"id": "kp1", "text": "Тезис", "weight": 2, "required": true}],
      "common_errors": ["Типичная ошибка"],
      "explanation": "Короткий разбор после ответа",
      "why_prompt": "Почему…?",
      "rationale": "Почему ответ именно такой: норма или принцип и вывод из них",
      "rationale_quote": "Дословная цитата из нормы, если уверен в тексте",
      "hints": ["Подсказка"],
      "options": ["Только для choice"],
      "correct_option": 0,
      "source": {"title": "ГК РФ", "locator": "п. 1 ст. 200", "url": "необязательно"},
      "norms": ["ГК РФ ст. 200"],
      "related_ids": ["deck-id-002"],
      "pretest": false,
      "valid_as_of": "ГГГГ-ММ-ДД"
    }
  ]
}
```

Поля, которые не нужны вопросу, можно не указывать. Пример готовой колоды: `examples/sample-deck.json`.
